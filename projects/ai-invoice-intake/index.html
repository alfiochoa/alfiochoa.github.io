AI Invoice Intake

Invoices in, a review queue out. An LLM extracts the fields, rules check them, and a person approves.

Open the live demoCode on GitHub

A short silent walkthrough. The diagrams are schematic illustrations, labelled as such in the video.

The problem

Re-keying invoices by hand is slow, and mistakes are caught late.

What it does

  • Takes a PDF or emailed text, extracts JSON with an LLM and falls back to rules if the LLM fails.
  • Validates totals, duplicates, the vendor whitelist and a grounding guard.
  • Anything doubtful waits in a human review queue with the reason shown. You edit the fields, then approve (exported to CSV) or reject (kept out).
  • FastAPI, Streamlit and SQLite.
